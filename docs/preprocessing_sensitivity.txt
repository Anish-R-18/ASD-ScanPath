RECOMMENDATION
--------------
Variant B (min_len = 3) is recommended.
Reasoning:
- Variant A (min_len = 4) has a severe 15% retention gap (TD 77% vs ASD 62%), which introduces strong group bias into the dataset.
- Variant B (min_len = 3) substantially reduces this gap while still providing enough temporal context (3 fixations) for the TPP-Gaze transformer to learn sequence dynamics.
- Variant C (min_len = 2) minimizes the gap further, but sequences of length 2 offer very little temporal history for a point process model, severely limiting the transformer's ability to capture complex spatial-temporal gaze patterns.
- All variants preserve valid scanpaths across all 300 images for both groups.
