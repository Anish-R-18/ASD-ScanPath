5. PARTICIPANT ID AUDIT (ARE PARTICIPANT IDS PRESENT ANYWHERE?)
--------------------------------------------------------------------------------
CONCLUSION: NO, explicit participant/subject IDs are NOT present anywhere in the dataset.

Detailed Evidence and Audit Checklist:
1. Scanpath Files (*.txt):
   - Header in all 600 files is strictly: 'Idx, x, y, duration'
   - No column exists for SubjectID, ParticipantID, Age, or Gender.
   - Filenames denote Image IDs (e.g. 'ASD_scanpath_1.txt' = Image 1), NOT participant IDs.
2. Within-File Structure:
   - Scanpaths for an image contain concatenated sequences separated by Idx resets (Idx = 0).
   - However, the order of segments is anonymous. There is NO metadata indicating which segment
     corresponds to which child.
3. Cross-Image Participant Tracking:
   - Individual subjects CANNOT be tracked across different images.
   - Segment #1 in Image 1 does NOT necessarily belong to the same child as Segment #1 in Image 2.
   - Furthermore, as documented in README.txt, ASD children frequently looked away from the screen,
     leading to missing recordings (segments per image vary between 8 and 17 for ASD and 9 to 15 for TD).
   - Because missing trials are omitted without placeholders, alignment across images is mathematically impossible.
4. ImageAnnotations.csv:
   - Contains 6 columns: [Image_Path, x1, y1, x2, y2, Label].
   - Contains purely semantic bounding boxes (face, people, car, etc.) - no participant information.
5. Code and Documentation (README.txt, ICME_DataPreparation.m, UsageAgreement.txt):
   - README.txt confirms children were aged 5-12 (mean age 8) and that 14 ASD and 14 TD children were recruited.
   - No demographic table, mapping table, or subject identification matrix is provided.

6. IMAGE DIMENSIONS VS FIXATION MAP DIMENSIONS
--------------------------------------------------------------------------------
A comprehensive audit was performed comparing the stimulus images with all generated maps:

Category        | Location                  | Files | Mode | Dimensions vs Original Images
----------------|---------------------------|-------|------|---------------------------------------------
Stimulus Images | TrainingData/.../Images   | 300   | RGB  | 70 unique dimensions (max dim 1024 px)
ASD FixMaps     | TrainingData/.../ASD_FixMaps | 300 | L   | EXACT MATCH (300/300 match image W x H)
TD FixMaps      | TrainingData/.../TD_FixMaps  | 300 | L   | EXACT MATCH (300/300 match image W x H)
ASD FixPts      | AdditionalData/.../ASD_FixPts | 300 | L  | EXACT MATCH (300/300 match image W x H)
TD FixPts       | AdditionalData/.../TD_FixPts  | 300 | L  | EXACT MATCH (300/300 match image W x H)
ASD HeatMaps    | AdditionalData/.../ASD_HeatMaps | 300 | RGB | MISMATCH (Enlarged due to MATLAB figure plot)
TD HeatMaps     | AdditionalData/.../TD_HeatMaps  | 300 | RGB | MISMATCH (Enlarged due to MATLAB figure plot)

Detailed Explanation of Dimension Behaviors:
1. FixMaps (*_s.png) & FixPts (*_f.png):
   - Exactly preserve the native stimulus dimensions of the corresponding image (e.g. 1024x681, 1024x768).
   - Color mode is 8-bit single channel ('L' grayscale).
   - FixPts contains binary coordinates: pixel values are strictly {0, 255}, where 255 marks a fixation center.
   - FixMaps contains continuous density values [0, 255] produced by convolving FixPts with a 1-degree
     Gaussian filter (kernel size 43*6 = 258, sigma = 43).
2. HeatMaps (*_h.png):
   - Dimensions do NOT match original images (e.g., Image 1 is 1024x681, but 1_h.png is 1869x1212).
   - Cause: As verified in 'ICME_DataPreparation.m' lines 60-72 and 94-106, heatmaps were rendered using
     MATLAB figure functions: figure(), imshow(Img), hold on, pcolor(meshX, meshY, FixationMap), colorbar,
     shading interp, alpha(0.4), and saved using saveas(HeatMap, ...).
   - This captured the MATLAB figure window GUI canvas (including axes, padding, and the colorbar) rather
     than exporting a raw image matrix.

7. COMPREHENSIVE EXPLANATION OF WHAT EACH DATASET FOLDER CONTAINS
--------------------------------------------------------------------------------
1. TrainingData/TrainingData/Images/
   - Contains 300 natural images in PNG format (1.png to 300.png).
   - Origin: Subsampled from the benchmark MIT1003 dataset.
   - Content: Varied natural indoor and outdoor scenes containing people, faces, objects, animals, and text.
   - Role: The visual stimuli shown to children during the eye-tracking experiment.

2. TrainingData/TrainingData/ASD/
   - Contains 300 plain text files (ASD_scanpath_1.txt to ASD_scanpath_300.txt).
   - Content: Raw fixation scanpaths recorded from children diagnosed with Autism Spectrum Disorder (ASD).
